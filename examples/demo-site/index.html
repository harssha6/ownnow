3steps to publish

How it works

The same three-step flow agents already know from here.now — except the infra is yours.

01 — CREATE

Declare the site

Tell the server what you're publishing. It reserves a slug like bright-canvas-a7k2 and hands back signed upload URLs.

02 — UPLOAD

Files go direct

Bytes upload straight to your object storage with presigned URLs. The server never touches them, so big files cost nothing extra.

03 — FINALIZE

Flip it live

One atomic switch makes the new version live. Every publish is kept, so rollback is a pointer flip, not a redeploy.

From folder to live link

What's included

Version history & rollback

Every publish is an immutable version. Preview, compare, and restore any of them.

Password & expiring sites

Lock a site with a password, or give it a TTL. Anonymous publishes expire in 24 hours with a claim token.

Wasm-ready

Correct application/wasm MIME and cross-origin isolation headers for games and in-browser apps.

Bring your own infra

Docker on any VPS, a single binary, or Cloudflare Workers + R2 for zero-egress edge serving. Your pick.

Agent-native

Ships with an agent skill, so Claude, Cursor, and friends can publish to your instance with one command.
